# c#

VisualStudio写一个dll

具体操作

在visualstudio中创建了一个类库应用，这里我选择第一个

实现dll，我写的如下

c#
namespace MyDll
{
    public class MyTestDll
    {
        public MyTestDll() { }

        public void Print()
        {
            Console.WriteLine("hello!");
        } 
    }
}

点击[你的项目]名字项目右键点击，点击生成，再在打开项目所在文件夹

打开bin/debug（或者release），找到你的项目名字.dll（我这里是MyDll.dll）,这就是你写的的dll啦，到此就实现了一个dll
